# kast

Демонстрационная концепция сайта ювелирного завода КАСТ.

Готовая сборка для GitHub Pages находится в [docs](docs/). Настройка Pages: branch `main`, folder `/docs`.

В репозитории опубликованы только файлы клиентского просмотра. Рабочие материалы, заметки, промпты и оригиналы изображений хранятся локально.

## Демонстрационные ограничения

Добавлены запрет индексации, минимизация кода, отсутствие source maps, блокировка перетаскивания и контекстного сохранения изображений, ограниченная печатная версия. Эти меры усложняют простое заимствование, но не могут полностью исключить скачивание файлов или создание скриншотов.

Подборки трёх направлений предварительные. Товарные переходы ведут на официальный сайт КАСТ. Брендовые материалы принадлежат их правообладателям.

## Контент главной

Специализация завода — бриллианты. На главной не использовать коммерческие фотографии украшений с изумрудами, турмалинами, сапфирами и другими цветными камнями. Это относится к первому экрану и товарной подборке. По прямому уточнению пользователя в разделе «Эксклюзив» сохранена исходная съёмка с моделью в белом платье: портрет с книгой и крупный план украшений. Не заменять её при изменении первого экрана. Yellow Diamond — коллекция именно бриллиантов.

Капсульные коллекции: все три фотографии в едином вертикальном формате 4:5, без полей. Для Just используется специально подготовленная вертикальная версия кадра с двумя реальными браслетами; не подменять её старой генерацией с одним браслетом.

## Оптимизация публикации

Сборка публикует только используемые ресурсы. Фотографии и вырезки конвертируются в WebP с прозрачностью, для разных экранов создаются варианты ширины; шрифты подключены в WOFF2. Имена ресурсов содержат хеш содержимого, CSS и JS минифицированы.

До первой очистки копия прежней папки docs сохранена локально в `work/pre-optimization-docs`. Исходные фотографии не удаляются. Для воспроизводимой установки зависимостей: `npm ci`, затем `npm run build`.

Правки типографики и «Эксклюзива»: заголовки без курсива; исходные фотографии сохранены, кадрируются через object-fit/object-position с акцентом на руках и перекрывают друг друга без обводки. Подзаголовок теннисных браслетов взят с главной kast-spb.ru: «Украшение, которое уместно везде: от утренней встречи до вечернего выхода».
